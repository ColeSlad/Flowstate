Feature & metric key

Workload

Traffic
Target rate: Quiet 10, Steady 150, Burst 1,200 queries/sec.
Results per query (top-K)
Number of highest-scoring matches returned.
GPU contention
A competing CUDA workload stresses the GPU.
Replay
Play, pause, seek, or jump to a recorded stage. Workload controls require a live runtime.

Routing & controllers

CPU latency
Execute queries on the CPU without batching.
GPU immediate
Execute queries on the GPU without batching.
GPU batching
Run several queries in one GPU call.
Balanced
Split new queries 50/50 between CPU and immediate GPU execution.
Heuristic / Laya
Rules / an experimental local model choose the policy. Laya falls back to rules on low confidence or errors.
Model confidence
Highest class probability, not measured scheduling accuracy.

Metrics

Incoming / completed
Measured arrivals / successful searches per second.
Queue depth
Waiting requests; excludes in-flight searches.
p95 / p99 latency
95% / 99% of successful searches finish within this time, including queue wait.
SLO misses
Queries exceeding the latency target, plus rejections and failures. SLO = service-level objective.
Rejected / failed
Queries refused by the runtime / accepted queries that errored.
Routing share / utilization
Share of successful completions / whole-machine CPU or GPU activity.
Mean GPU batch / free GPU memory
Average queries per GPU batch / available device memory.

Dashboard rates and percentiles use a rolling 1-second window. Percentiles are histogram upper bounds, rounded up by at most 10%. Cumulative counters include runtime startup.
